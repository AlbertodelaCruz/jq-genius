# **App Name**: JQ-Genius

## Core Features:

- File Upload: File Upload: Allow users to upload a JSON file to be queried.
- AI Query Generator: Natural Language to JQ Query: Use AI to convert natural language input into a JQ query. This feature acts as a tool to generate and validate the query.
- Query Execution: JQ Execution and Result Display: Execute the generated JQ query on the uploaded JSON file and display the results in a readable format.

## Style Guidelines:

- Primary color: Dark blue (#2c3e50) for a professional look.
- Secondary color: Light gray (#ecf0f1) for backgrounds and subtle contrast.
- Accent: Teal (#3498db) for interactive elements and highlights.
- Clean and modern sans-serif font for readability.
- Simple and clear icons for actions like upload, generate, and execute.
- Split-screen layout with input (natural language) on one side and output (JQ query and results) on the other.
